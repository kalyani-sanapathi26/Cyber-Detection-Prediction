# Cyber Hate Detection Prediction Using Machine Learning

This project focuses on detecting cyber hate speech using Machine Learning algorithms and NLP techniques. The dataset was collected from Kaggle and processed for prediction analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Matplotlib

## Features
- Data preprocessing
- Text cleaning
- Model training
- Prediction system
- Accuracy evaluation

## Dataset
Dataset collected from Kaggle.

## Machine Learning Algorithms
- Logistic Regression
- Naive Bayes
- Random Forest
- SVM

## Future Improvements
- Deep Learning integration
- Real-time prediction
- Web deployment
